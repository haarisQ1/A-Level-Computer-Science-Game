# A-Level-Computer-Science-Game
My A-Level Computer Science Project Game | Tuff Trace - Aim trainer

# Overview
I created this aim trainer to help people improve in games where accuracy is a crucial skill. This game helps improve accuracy by making the player try to continuously hit the target and compete with their friends to try and get the best score they can achieve. 

# Technology
Coded in Python
Ursina engine - Python-based game development engine used to create the game's 3D environment, objects and interactions

# Features
Includes moving target players have to hit
Includes an accuracy meter so players know how accurate they are
Includes a timer to alert players of how long they have left
Includes a point system
Includes 10 different levels each with increasing difficulty
Includes a menu and leaderboard system

# Development
Originally was meant to make use of a 2.5D approach to achieve the 3D feeling in the aim trainer, which later got changed to using ursina engine to implement the 3D features instead. Includes many prototypes for both the login system and the game itself, all which were tested thoroughly to ensure no problems persisted. Any occurring issues were later fixed in later prototypes (unless stated otherwise). Towards the end of development, I had noticed one major issue regarding different devices playing the aim trainer - differing FPS values changed the amount of points earnt upon hitting the target. This meant players with higher average FPS achieved a higher score on hitting the target than someone with lower average FPS.
